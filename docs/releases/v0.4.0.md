# Resource Queue Manager (FIFO) — v0.4.0

**Initial public release candidate — experimental.**

Resource Queue Manager (FIFO) is a custom Home Assistant integration for scheduling a fixed number of simultaneous logical reservations using a first-in, first-out queue.

### Features

- Persistent FIFO reservations, waiting queue, and resource-to-entity mappings across Home Assistant restarts.
- Configurable capacity (1–50 concurrent slots), using an editable numeric field.
- Native Home Assistant configuration for explicitly supervised `light` and `switch` entities.
- Four diagnostic sensors: `resource_queue_active`, `resource_queue_waiting`, `resource_queue_available`, `resource_queue_status`.
- Fail-closed manual recovery: starts `paused`; `resource_queue_manager.resume` checks monitored entity states before restoring reservations.
- Actions: `request`, `release`, `cancel`, `resume`.
- Slot-granted event: `resource_queue_manager_slot_granted`.
- New minimal Resource Queue Manager RQ brand icon.

### Important safety and compatibility notes

- **Experimental:** This is *not* a certified electrical load-shedding or overcurrent protection system. Actual devices are switched only by user automations; devices outside supervision are unaffected.
- A relay or switch must report `off` to release an active reservation.
- The old `heating_queue_manager` domain is **incompatible** with this release. Existing automations must be updated to `resource_queue_manager`; change `heater_id` to `resource_id` and `relay_entity_id` to `entity_id`.
- This clean-install release does not migrate old persistent reservations or config entries.
- Re-enable real heating only after validating one-device FIFO and independent heater safety behavior.

### Installation

For Home Assistant 2026.11+, go to **Settings → Marketplace → Add from link** and provide `https://github.com/HamzaKarfa/Resource-Queue-Manager`. Install, restart Home Assistant, add Resource Queue Manager (FIFO), select supervised entities, and manually call `resource_queue_manager.resume` after inspecting their states.

See [the complete README](https://github.com/HamzaKarfa/Resource-Queue-Manager#readme).
